Day-ahead prices

A small data file with the day-ahead electricity prices for the Netherlands, per hour, in EUR/kWh, refreshed every day: day-prices-NL.json.

Data: Bundesnetzagentur | SMARD.de, licensed CC BY 4.0. Converted from EUR/MWh to EUR/kWh, one value per hour (the mean of the four quarter-hour prices). Prices exclude taxes and supplier fees.
